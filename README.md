# Single site OLB settings prototype

Clickable HTML prototype of the Figma single-site MVP flow:

[Appointment reasons — online booking](https://www.figma.com/design/yiIxGUoRw4KNFxKhpjhN1Y/Appointment-reasons---online-booking?node-id=6983-60017)

## Open locally

```bash
open index.html
```

Or serve it:

```bash
npx --yes serve .
```

## Flow covered

1. Appointment reasons table
2. Create appointment (empty checklist → filled with practitioners)
3. Edit appointment
4. Online booking settings (Settings + Plans tabs)
5. Plan edit (Den plan AA)
6. Notification settings

Sidebar navigation works across all settings screens.
